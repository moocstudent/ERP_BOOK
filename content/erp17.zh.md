## 核心讲义

### 补货的两个问题:何时订、订多少

库存管理的一切策略,归根结底在回答两个问题:**什么时候下单(when)**与**一次订多少(how much)**。再订货点法把「when」变成一条自动规则:

```
再订货点 ROP = 日均需求 d × 提前期 LT + 安全库存 SS
```

库存一路消耗,跌破 ROP 的瞬间触发订货;等待到货的 LT 天里,靠「提前期需求 d×LT」撑着;如果一切如平均值,货到时库存恰好剩 SS。这就是沙盘里那条**锯齿曲线**:消耗下坡 → 触发 → 等待 → 到货跳升,周而复始。

### 安全库存:为「不平均」买的保险

如果需求每天精确等于平均值、供应商永不迟到,SS = 0 也没事。现实中两种波动都存在:

- **需求波动**:平均 20 件/天,某周冲到 35;
- **提前期波动**:说好 7 天,偶尔 12 天。

安全库存的统计公式(正态假设):

```
SS = z × σ_LT需求
z:服务水平系数 —— 90% → 1.28,95% → 1.65,99% → 2.33
σ_LT需求:提前期内需求的标准差
```

**最重要的直觉:z 是非线性的。** 从 95% 提到 99% 服务水平,安全库存要增加 ~41%(2.33/1.65);再往 99.9% 走,还要再加一大截。「永不缺货」的代价是指数增长的库存——所以服务水平是**分级决策**:A 类关键料 99%,C 类通用料 90%,让缺货成本与持有成本各得其所。

降低 SS 的正道不是拍脑袋砍数字,而是**压缩波动**:供应商准时率上去了、预测准了,σ 变小,SS 自然瘦身。

### 订多少:EOQ 的思想与现实

**经济订货批量(EOQ)**平衡两种成本:

```
EOQ = √(2 × 年需求 D × 单次订货成本 S / 单件年持有成本 H)
```

- 订得越勤:订货成本(下单、运输、验收)高,持有成本低;
- 订得越大:反之。EOQ 是总成本曲线的谷底。

现实中的批量还要叠加:供应商起订量、整箱/整托约束、价格折扣档、仓容与效期上限。EOQ 的价值不在算出精确数字,而在**提醒你总成本有一个谷底**——曲线在谷底附近很平缓,取个「够接近的整数」就好。

### 策略选型:不是所有物料都配 MRP

| 方法 | 适用 | 特点 |
| --- | --- | --- |
| MRP(按需求展开) | A 类、结构件、需求可从 BOM 推导 | 精确,但依赖数据质量 |
| 再订货点(消耗驱动) | C 类辅料、需求平稳的通用件 | 简单皮实,不看未来 |
| 看板/两箱制 | 线边低值件 | 物理信号,零系统操作 |
| 按单采购 | 定制件、项目料 | 零库存,提前期长 |

经典组合拳是 **ABC 分析**(按金额)× **XYZ 分析**(按需求稳定性):AX 用 MRP 精管,CZ 用两箱制放养——把管理精力花在值得的地方。

## 练习

1. 计算:d=30 件/天,LT=10 天,σ_LT=45 件,要求 95% 服务水平。求 SS 与 ROP;若服务水平提到 99%,SS 增加多少件、多少 %?
2. 用 EOQ 公式算:年需求 24,000 件,订货成本 ¥200/次,持有成本 ¥6/件·年。EOQ 是多少?供应商整托 500 件,你实际订多少?为什么无伤大雅?
3. 给这四种物料选补货策略并一句话说明:发动机总成、包装纸箱、定制铭牌、螺丝。
