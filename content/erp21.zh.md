## 核心讲义

### 财务会计 vs 管理会计

同一套分录,两副眼镜:

- **财务会计(FI)**:对外——给股东、税务、银行看。按准则编报,回答「公司整体赚了多少」;
- **管理会计(CO,controlling)**:对内——给管理层看。不受准则约束,回答「**哪个产品、哪个部门、哪张订单**赚的/亏的」。

ERP 的巧妙在于两者共享底层凭证:每笔费用分录除了记科目(FI 视角),还同时记**成本对象**(CO 视角)——电费 ¥8,000 记入「制造费用」科目 + 「注塑车间成本中心」。一笔录入,两套视角。

### 成本对象:费用的「收件人」

| 成本对象 | 回答的问题 | 例 |
| --- | --- | --- |
| **成本中心(cost center)** | 这个部门/工段花了多少 | 注塑车间、质检部、IT 部 |
| **内部订单(internal order)** | 这个专项活动花了多少 | 一次展会、一个改造项目 |
| **生产工单** | 这批产品实际花了多少 | MFG3 已讲 |
| **获利能力段(profitability segment)** | 按产品×客户×区域切利润 | 26寸车×华东×经销 |

规则:**每笔损益类过账必须带一个成本对象**——没有收件人的费用无处安放,期末也无法分析。

### 两步法:归集,然后分摊

费用发生时先**归集**到直接责任的成本中心。但有些成本中心(水电、维修、IT)是**服务部门**,它们的成本最终要**分摊(allocation)**给生产部门,再进产品:

```
第一步 归集:电费 80,000 → 动力车间成本中心
第二步 分摊:动力车间 → 各生产车间,按「电表读数」分
第三步 进产品:生产车间费用 → 按机时费率进工单
```

**分摊基准(allocation base)**决定公平性:电费按电表、房租按面积、IT 按人头、质检按检验批数。基准选得差(全按人头),产品成本就被扭曲——高耗电产品被补贴,低耗电产品被冤枉。**作业成本法(ABC)**就是把「基准」推到极致:找出每项作业的真实动因。

### 作业费率:服务的「内部价格」

生产成本中心把自己的费用变成**作业费率(activity rate)**:

```
注塑车间月费用 ¥360,000,可用机时 3,000 小时
→ 机时费率 = ¥120/小时
工单报工 2.5 小时 → 吸收 ¥300 制造费用
```

年初用**计划费率**(计划费用/计划工时),年末实际数出来后差异清算。费率是车间效率的镜子:费用没降但开工不足,费率飙升——「产能闲置成本」就这样现形。

### 成本卷积:标准成本的诞生

**成本卷积(cost roll-up)**自下而上算出产品的标准成本:

```
材料:BOM 每行 = 子项标准价 × 用量,逐层向上累加
人工:工艺路线每道工序 = 工时 × 人工费率
制费:工时 × 制造费用率(或按人工的 %)
```

沙盘里拖动车轮价格看成品成本联动,就是卷积的实时演示。卷积结果「冻结」为本年度标准成本(INV3 的 S 价从这里来),之后:实际 vs 标准 → **差异分析**:

- **价差**:买贵了/买便宜了(采购的责任);
- **量差**:超耗/节约(车间与工艺的责任);
- **费率差**:费用超支或开工不足(管理与销量的责任)。

差异按责任归属,才能奖惩有据——这是管理会计「用数字管理」的完整闭环。
